# 🚀 Odyssey Launcher

**Der schöne, schnelle Minecraft-Launcher**

Ein moderner Launcher im Geiste von Lunar Client – mit Internet-Chat, Freunden,
Mods, Modpacks und mehr. Entwickelt mit 💙 für die Community.

## 📥 Download

Lade die neueste Version für dein System herunter:

| Plattform | Installer |
| --- | --- |
| 🪟 **Windows** | [`Odyssey-Launcher-Setup.exe`](https://github.com/MoritzHuyer/odyssey-launcher/releases/latest/download/Odyssey-Launcher-Setup.exe) |
| 🍎 **macOS (Apple Silicon)** | [`Odyssey-Launcher-arm64.dmg`](https://github.com/MoritzHuyer/odyssey-launcher/releases/latest/download/Odyssey-Launcher-arm64.dmg) |
| 🍎 **macOS (Intel)** | [`Odyssey-Launcher-x64.dmg`](https://github.com/MoritzHuyer/odyssey-launcher/releases/latest/download/Odyssey-Launcher-x64.dmg) |
| 🐧 **Linux** | [`Odyssey-Launcher.AppImage`](https://github.com/MoritzHuyer/odyssey-launcher/releases/latest/download/Odyssey-Launcher.AppImage) |

> **Windows-Hinweis:** Beim ersten Start kann Windows eine SmartScreen-Warnung zeigen – das ist normal für
> nicht signierte Apps. Klicke auf „Trotzdem ausführen“, um den Launcher zu installieren.

> **macOS-Hinweis:** Falls macOS die App als „beschädigt“ meldet: Rechtsklick → **Öffnen**,
> oder im Terminal `xattr -cr "/Applications/Odyssey Launcher.app"` ausführen.

## ✨ Features

- 🎮 **Microsoft-Anmeldung** – dein Minecraft-Konto, einfach verbunden
- 💬 **Internet-Chat** – Gruppenchat, private Nachrichten und Freunde, von überall
- 📦 **Mods & Modpacks** – Modrinth und CurseForge direkt im Launcher
- 🧵 **Instanzen** – separate Profile für jede Mod-Kombination
- 🧊 **Skins & Capes** – dein Profil direkt verwalten
- 🕹️ **Odyssey Client Core** – PvP-HUD und mehr (Fabric)
- 🔄 **Auto-Updates** – der Launcher aktualisiert sich von selbst

---

## 🚦 Erste Schritte

1. **Installiere** die passende Version von oben.
2. **Melde dich an** mit deinem Microsoft-Konto (Minecraft erforderlich).
3. **Wähle eine Version** und klicke auf **Spielen** – fertig!

Der Launcher kümmert sich um Java, Libraries und Assets automatisch.
